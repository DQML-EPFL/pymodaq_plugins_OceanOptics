Instruments
===========

This plugin has been tested and designed for the OceanOptics spectrometer series HR2, but should work for other series of OceanOptics spectrometers.



Installation instructions
=========================

Tested on : 

* PyMoDAQ version 5.0.18.
* Windows 11 24H2.
* Drivers are included in the plugin.
